**Syntax:**
```
.var <name> <integer|boolean>      ; declare a variable, anywhere in the file
label:                             ; a label, alone on its own line
MNEMONIC [operand]                 ; one instruction per line
; a comment
```
- `PUSH` takes an integer literal; `LOAD`/`STORE`/`READ` take a variable name; `JMP`/`JZ` take a label name; everything else takes no operand.
- Two-pass assembly, so both labels and variables can be forward-referenced — essential for things like `jz done` where `done:` appears later in the file.
- Mnemonics and type names are case-insensitive (`PUSH`/`push`/`Push` all work); variable and label names are case-sensitive — deliberately matching how the Pascal compiler's own lexer/parser already behave.
- Errors report `file:line: Assembler Error: ...` and recover cleanly via the same `fatal_abort()` mechanism as the rest of the toolchain (verified: undeclared variables, undefined labels, unknown mnemonics, duplicate labels/variables, wrong/missing operands, and unknown types all produce a correct diagnostic and clean exit rather than a crash).
