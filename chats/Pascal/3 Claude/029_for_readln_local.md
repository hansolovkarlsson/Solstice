## What's implemented and thoroughly verified

**Local `for`-loop variables**: desugared entirely at parse time — the loop variable becomes a genuine local frame slot (per-call isolated), and critically, the hidden end-bound cache also becomes a local slot (reserved via `add_local` during parsing, before the enclosing procedure's local count is finalized), built as an ordinary `NODE_LOCAL_ASSIGN` wrapped in a `NODE_COMPOUND`. This matters because if only the loop variable were isolated but the bound cache stayed global, a recursive function with a local for-loop would still corrupt its bound across recursive calls.

**`readln` into a parameter/local**: five new per-type opcodes (`OP_READ_LOCAL_INT/BOOL/REAL/STR/CHAR`), chosen at compile time rather than via `OP_READ`'s runtime type dispatch — necessary because a local frame slot carries no runtime type tag the way a global `sym_table` entry does.
