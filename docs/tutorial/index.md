# Pascal Tutorial

A from-scratch walkthrough of the Pascal dialect `pascalc` accepts —
no prior Pascal experience assumed. Every example in this tutorial is
actually compiled and run against the real toolchain, so what you see
is exactly what you'll get if you type it in yourself.

This covers the **core language** — everything you need to write real,
useful programs: variables and types, expressions, input/output,
control flow, procedures and functions, arrays, strings, and records.
It deliberately stops there — object-oriented Pascal (classes,
inheritance, pointers, exceptions, units) is a large enough topic to be
its own follow-on tutorial once this one is complete, and isn't needed
to read or extend this project's own compiler internals.

Once you've worked through this, the [Language
Reference]({{ site.baseurl }}/LANGUAGE.html) documents the complete
accepted dialect, core and beyond, in one place.
